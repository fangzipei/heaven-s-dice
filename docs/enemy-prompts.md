# 全敌人四态立绘提示词

适用：折纸手绘 / 纸雕质感、透明背景、正面朝向镜头、同一角色四态一致。每张先生成 `idle`，再拿它作为角色参考生成另外三态。

## 通用规格

- 生成尺寸：**1200×1600 px，3:4**
- 详情尺寸：**480×640**
- 缩略图：**120×160**
- 透明 PNG；不要生成背景、纸张卡片、边框、文字
- 每张图都使用下面的负向词

### 通用负向词
```text
photorealistic, 3D render, plastic, glossy, clay, anime, chibi, cute mascot, soft plush, watercolor wash, blurred, low contrast, background scenery, room, table, floor, frame, text, letters, logo, watermark, multiple characters, duplicate body, extra limbs, extra fingers, cropped head, cropped feet, out of frame, deformed face, asymmetrical eyes, melted paper, flat unlit, oversaturated neon, cast shadow, drop shadow
```

### 状态切换逻辑
| 状态 | 文件 | 用途 |
|---|---|---|
| 常态 | idle.png | 默认 |
| 攻击 | attack.png | 玩家投掷/敌人施压 |
| 被攻击 | hit.png | 玩家成功计分 |
| 残血 | critical.png | 玩家接近/达到目标 |
