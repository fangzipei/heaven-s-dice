# 《天国骰局》语气与台词全量预案（轻松版）

> 配套文档：[docs/worldbuilding.md](worldbuilding.md)（世界观底稿）
> 本文档只谈**语气、台词、场景氛围**，不涉及任何数值与平衡改动。

---

## 零、先说结论：改造成比想象中小

通读全部现有文案后，有三个发现，直接决定这次改版的工作量：

1. **大部分台词天然就是轻松调的。** 现有的事务性用词（"取证""核销""这一页我记下了""凑齐三颗再和我说话""它总想和左边那颗并排走"）已经是**办事大厅式的调侃**，不是恐怖叙事。
2. **真正带恐怖色的只有 5~6 处**：成双之忌的"烧掉"、炭手的"骨头也锻一锻"、腐牙伯爵的"血腥味"、以及"灵魂被铸成骰子"这个**设定本身**。
3. **有一处现存的逻辑不一致必须顺手修**（见 §5.2 铁面铸魂师）：效果写的是熔毁 **5 点**，intro 和两条 taunt 却都在说 **6 点**。

所以这次的工作重心不是"重写所有台词"，而是**换掉设定 + 替换那几处硬词 + 给五个场景定新氛围**。

## 一、新基调

### 1.1 一句话

> **死后排到号，掷一颗骰定去向。**
> 掷得好，去个好地方；掷得差，去个苦地方；**掷空了——你就变成一颗骰子，等下一个来掷你。**

恐怖被降级成**排队与转岗**：变成骰子不是刑罚，是"恭喜入职往生坊骰子组"。

### 1.2 为什么要这么改

| | 旧设定（恐怖） | 新设定（轻松） |
|---|---|---|
| 骰子是什么 | 被剥离灵魂后压铸的容器 | **一颗签**：决定你去向的号牌 |
| 失败意味着什么 | 灵魂被吞噬、被熔铸 | **转岗当骰子**，等后人投掷 |
| 地狱是什么 | 惩罚与刑场 | **往生坊**：一栋办手续的大宅子 |
| 玩家在做什么 | 逃亡 | **想自己挑个好归处，所以得赢上去** |
| 恐怖来源 | 身体与毁灭 | **排队、比手续、讲规矩、赌气** |

### 1.3 七条语气规则（写新文案时照着走）

1. **恐怖 → 事务。** "被烧掉"→"回炉"；"被啃"→"被数到"；"血肉"→"点数"。
2. **庄家都是打工的，不是恶魔。** 他们可以抱怨、摸鱼、跟你套近乎，甚至有点同情你。
3. **不喊叫。** 全部用平淡的、公事公办的语气。**越平越好笑**。
4. **保留市井热络。** 叫卖、寒暄、讨价还价、"再来一局嘛"。
5. **每句台词都要能"勾着玩家再掷一次"。** 台词的功能是让人想继续，不是吓人。
6. **锋利只留给角色个性**，不留给恐怖：税吏的斤斤计较、路西法的漂亮话、撒旦的从容。
7. **自嘲优先。** 庄家偶尔自嘲自己的处境（发了一辈子骰子、自己那颗还没掷）。

### 1.4 撒旦怎么改（这是新基调的支点）

旧设定：撒旦是被逐天堂的首席庄家，与天堂争"命运该谁掷"，所以阴郁。

新设定下保留全部戏剧性，但换成轻松版：

> **撒旦是往生坊的掌骰人。** 他给每一个游魂发骰子，唯独**自己那一颗从来没掷过**。
> 他不害人，他只是**不肯让别人替自己掷**。
> 所以他一直在等——等一个能赢过他、能自己掷出自己那颗骰子的人。

反转同步成立：

- 24 关后的"天堂"其实是**往生坊的公示厅**（挂满写好去向的牌子），不是天堂，只是一个大厅。
- 三位天体庄家是往生坊的**核销员/复核员**，负责确认"这一手算数"。
- 见到撒旦 = **有资格领取自己那颗骰子**。
- 打败撒旦 = 他把手里那颗**从没用过**的骰子交给你，**你自己掷**。那才是真正的"决定自己去哪"。

### 术语落点（建议实际改动的字段）

- `satan.title`：**天堂的主人 → 掌骰人**。"天堂的主人"降级成他在公示厅自封的招牌。
- `satan.effectName`：**撒旦的恩赐 → 撒旦的优待**。
- 右栏「本关契约」→ 可改**「本关约定」**（更轻）。
- 商店「市集」→ 建议保留，但加副题**「骰子市」**。

## 四、商店 / 市集氛围

### 4.1 定位

**「骰子市」——深夜还开着的旧货夜市。**

摊上摆的骰子，都是**已经去过某个地方的游魂用剩的**。摊主热情推销，样品骰在灯下转，摊主还会给你讲这骰子原来的主人。

### 4.2 一句话立住"去恐怖化"

> 「这颗是从一位老先生手里收的。他去的地方不错，可惜路上没带够钱。」

——用**一句闲话**把"灵魂变骰子"降级成旧货市场。

### 4.3 货品描述口径

| 旧口径 | 新口径 |
|---|---|
| 圣物 / 邪物 / 遗器 | **旧货 / 纪念品 / 别人用剩的** |
| 契约 / 献祭 | **约定 / 转让** |
| 诅咒、代价 | **代价**（保留，但注明"可商量"） |
| 掉落说明 | 「只有击败这位庄家的人才会得到它。」→ **保留**（这句本来就好） |

### 4.4 UI 小改

| 位置 | 旧 | 新（建议） |
|---|---|---|
| `app.ts:730` | 市集没有开门。 | **市集今天没开摊。** |
| 右栏标题 | 本关契约 | **本关约定** |

## 六、骰子 / 骰桶 / 物品的 flavor 改写方向

不必逐条重写（38 骰 + 19 桶 + 43 物），**给一条统一规则 + 分类方向**即可。

### 6.1 统一规则

> 把"灵魂/血/噬/啃/焚"换成 **"旧主人生前的习惯、口头禅、次数、纪念"**。
> 一颗骰子的 flavor 应该让人想到**一个人**，而不是一场灾难。

### 6.2 分档

| 档 | 现状 | 方向 |
|---|---|---|
| **A. 不用动**（约 60%） | 「只掷一和五。这两面，是赌桌上唯一能单独换钱的面。」「它总想和左边那颗并排走。」「每关醒来，它都换一副面孔。」「骰子已经停了，桌面还在震」 | 原样保留。这些本来就是轻快的。 |
| **B. 换恐怖词**（约 25%） | 「它不吞骰子，它只把骰子的名字吃掉，留下一个空壳。」「月全食那晚，整片森林都听见了骨头里的回声。」 | 换成"旧主人的事"。<br>示例：**噬名者** →「它把骰子的名字吃掉，只留下一个空壳。据说空壳里偶尔还会有人叫你的名字。」<br>**狼祖骰** →「月全食那晚，森林里所有的狼一起叫了整夜。」 |
| **C. 需要重写设定**（狼裔 / 恶魔两套） | 「它从不嚎叫。它只是看，群狼便知道该咬住哪一个数字。」「第一头狼的牙床。三这个数字，是它先咬出来的。」 | 改成"狼群的习性"，不写"牙床/咬"。<br>示例：**狼祖骰** →「狼群里的规矩比骰面还老：先落地的三，才算数。」 |

### 6.3 骰桶（19 只）

现状大多是纯机制描述（"1、5 出现率提高"），**只需把少数带黑暗意象的补一句轻 flavor**。例：
- **恶魔契桶**：「它闻得出赖子。老手都这么叫。」
- **五芒桶 / 旋涡桶**（仪式）：保留"抽签"的民俗感，**这是民俗不是邪术**，正好契合新调性。

### 6.4 物品（43 件）

机制描述**一个字都不用改**。flavor 按 §6.1 调。
**特别注意「幸运币」**：它现在有个隐性身份（伪天堂门房塞的见面礼）。新调性下这个伏笔可以保留但更轻——**往生坊给新人的"排号礼"**。建议 flavor 补一句：「往生坊发给新来排号的人。数目不多，够买一碗热汤。」
