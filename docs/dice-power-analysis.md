# 骰子强度分析（基于线上历史对局）

数据源：`hd_runs` 线上对局，共 **230 局 / 17 名玩家**，其中 212 局峰值关卡在 1–25 之间（18 局超过 25，视为测试或异常局，已剔除）。

- 平均峰值关卡：**11.3**
- 每次计分的单骰平均贡献：**338 分**
- 胜率口径说明：只有停在结算界面的局才记为 `win`，与「是否打到第 25 关」不是同一件事，因此本文用**峰值关卡 + 单骰贡献**判断强度，不用胜率。

## 方法

单看「买了它的局赢得多」会有幸存者偏差：能买到骰子说明已经活到商店。所以用了三个更干净的代理指标：

| 指标 | 含义 | 局限 |
|---|---|---|
| `早期入手` | 第 10 关前就买到它的局数 | 只统计能到商店的局 |
| `早期峰值` | 这些局最终打到的平均关卡 | 玩家水平会混进来 |
| `单骰贡献` | 该骰参与计分时，`本手得分 ÷ 选中骰数` 相对全体的倍数 | 大组合会摊薄单骰贡献 |

三个指标同向时结论最可靠；只有一个指标高时，标记为「待观察」。

## 值得单独说的几件事

1. **狼套组整体偏弱。** 乳狼、血月、白狼王三枚的单骰贡献都在 ×0.5–0.65，早期峰值 8.7–10.4，明显低于 11.3 的平均线；只有狼祖在后期拿到时表现尚可（×2.82，但样本仅 45 次）。三面偏科在实战里不如「稳定出分」。
2. **连记骰与商人骰是当前最强成长轴。** 连记早期峰值 23.4，商人 22.2，两者都在「越早拿越赚」的位置；单骰贡献分别是 ×3.15 与 ×4.01。
3. **衡心骰被低估。** 31 局早期入手，峰值 19.7，单骰贡献 ×2.54，是目前最稳的通用解。
4. **壹面骰是典型「看起来好用」的陷阱。** 36 局早期入手，峰值只有 15.7，贡献 ×1.59，远低于同价位的衡心/连记。
5. **单面骰里只有伍面骰站得住。** 壹/贰/叁/肆/陆都在 ×0.57–1.28，伍面 ×1.77。
6. **看客、朝圣、骰王、无冠女王、税吏样本太少**，现有数据不足以判断，别急着改。
7. 数据里还有 `standard`、`demon_seal`、`wolf_hunter` 三个已不在正式列表里的旧 id，可能是早期存档或测试局，未纳入排名。

## 如果要调，建议优先级

| 优先级 | 对象 | 方向 |
|---|---|---|
| 1 | 狼套组（乳狼 / 血月 / 白狼王） | 提高三面权重或加「三条 3」的套装联动，让偏科能兑现 |
| 2 | 连记骰 / 商人骰 | 成长曲线略微收敛，否则早期拿到就锁定胜局 |
| 3 | 壹面骰 | 降价或把 +100 提高，让它和「40% 出 1」的风险匹配 |
| 4 | 看客 / 朝圣 / 骰王 | 先加出场率，攒样本再动数值 |

> 以上是数据观察，不是改动。真要调数值，建议一次只动一个套组，再用同样的脚本复核。
