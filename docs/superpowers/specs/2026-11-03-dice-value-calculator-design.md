# 骰子设计方向与通用收益计算器 — 设计（已批准）

日期：2026-11-03 · 状态：用户已按推荐批准

## 一、骰子设计方向（清单，暂不实装）

按未被现有 36 骰占用的机制轴划分，每个方向先出方向、数值由计算器验证后再逐颗添加：

1. **桶共鸣系**：骰子读取当前骰桶属性获得加成（如概率桶偏置面 +30%）；叛律型可无视桶的强制效果。重铸桶上线后价值翻倍。
2. **经济系**：进店加币、按得分比例折币（喂给计算器的金钱轴）。
3. **成长系**：局内随计分次数/关卡数成长（淬火型负开局正终局）。
4. **重投操纵系**：免费重投、重投落空补偿。
5. **风险/方差系**：高 EV 高方差（小概率赖子/空白，概率面加权补偿）。
6. **反制庄家系**：boss 关封锁点数替代计分、目标削减。
7. **生态位系**：回应点数分布形态本身（如恰好 3 种点数 +180）。

约束：免费骰须 TV>0.1 或带 bonus；价格按 35/70/130/210 阶梯；传说新增会稀释传说池（计算器量化）。

## 二、通用收益计算器（方案 B：新建 `tools/dice-value.mjs`）

与 `tools/dice-ev.mjs`（单骰体检）分工：dice-value 答"这颗骰值不值、多久回本、多容易买到"。

### 指标（四轴）

对每颗骰，bag = [该骰] + 5 标准骰，对照 6 标准骰基准，共随机数配对（同 trial 同种子）：

| 轴 | 指标 | 算法 |
|---|---|---|
| 强度 | L4/L9/L13/L18/L23 关卡分 Δ、达标率 | 贪心策略模拟（复用 dice-ev 的 playLevel），快照等级取非庄家关、覆盖四个商店权重带 |
| 金钱 | 每关金币 EV Δ、回本关数、剩余净收益 | 金币 EV 直接取模拟中 `awardLevel` 实际入账（含未用重投折算、超额奖励、+10% 系数）；回本 = 价格 ÷ 金币Δ@L9；净收益 = Σ(快照 L'≥L9 的金币Δ × 5) − 价格 |
| 获取 | 各带出现率、期望店数、期望获取成本 | 用真实 `createShop` 蒙特卡洛（天然含稀有度带权重、恶魔 ×0.5、已持有套装 ×1.5、unique 过滤）；期望成本 = 价格 + 20 × (1/P − 1)，假设每店多刷一次基价货架 |
| 综合 | 三轴归一加权：强度 50% + 经济 30% + 获取 20%（`--w=` 可调） | min–max 归一后加权，映射 S(≥0.75)/A(≥0.55)/B(≥0.35)/C |

### CLI

```
node tools/dice-value.mjs [--trials=600] [--shop=20000] [--level=9] [--w=50,30,20]
                          [--bag=id1,...,id6] [--die=id] [--rarity=common]
                          [--quick] [--json]
```

- 默认：全骰表四张（强度/金钱/获取/综合）+ 告警（金币Δ≤0 高价骰、回本超剩余关数、稀有度倒挂）+ 自检。
- `--bag`：评估任意 6 骰阵容 vs 基准（补 `standard` 到 6 位），只出强度+金钱表。
- `--json`：机器可读输出。
- 表格沿用 dice-ev 的 CJK 对齐风格。

### 自检（工具内置）

1. 基准两次运行同种子结果逐位一致（配对 RNG 有效性）。
2. 蒙特卡洛各骰出现次数总和 ≈ 骰位数 × 试验数（货架填满）。
3. 传说骰在 L4 出现率 < 6%（权重带约束）。
