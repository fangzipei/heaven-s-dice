# 24 关分数曲线与庄家池

## 无庄家曲线：按百分比增长

分数曲线按三段复利增长：

- 1–7 关：每关 **+7%**
- 8–15 关：每关 **+9%**
- 16–24 关：每关 **+11%**

庄家关只把本关的无庄家目标乘上该庄家稀有度的系数；下一关回到无庄家曲线，不继承庄家倍率。

百分比按各阶段商店期望提升设定。四段期望商店价值约为 1.65 → 2.29 → 3.14 → 3.69；庄家遗物进一步抬高上限，因此把无庄家目标增长率设为 7% → 9% → 11%，让目标涨幅跟得上每段商店的期望提升，而不是线性硬加固定分数。
