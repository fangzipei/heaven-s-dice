## 7. 缩略图结论

| 资产 | 是否需要独立缩略图 | 建议 |
|---|---|---|
| 骰子 | **不需要额外生成** | 已有 `*-thumb.svg`（96×96）；SVG 可直接用 CSS 缩放到 40–64px，再生成不会更清晰 |
| 物品 | **不需要额外生成** | 已有 `*-thumb.svg`（96×96）；与完整 SVG 同源 |
| 骰桶 | **不需要额外生成** | 已有 `*-thumb.svg`（96×96）；杯身单独用 `*-cup.svg`（340×400） |
| Boss/小兵立绘 | **需要** | 状态 PNG 较大；列表/图鉴用 120×160，详情用 480×640 |

当前 `thumb` 文件更多是设计预览/预留，不是运行时性能必需。真正需要缩略图的是后续的 1024×1024 状态立绘。

| 状态 | 文件名 | 建议尺寸 |

## 10. 需要留意

- 骰子/物品/骰桶的 SVG 源尺寸已经是 512，显示只有 40–100px，不需要再放大。
- `assets/portraits/paper` 的 320×420 和 360×480 混用，会让不同敌人的视觉高度不一致。
- `assets/art/dice` 有 41 套，但内容表只有 38 枚；`standard`、`demon_seal`、`wolf_hunter` 可清理。
- `assets/cups`、`assets/rooms`、`assets/portraits` 更像旧版/备用素材，建议确认引用后再删。
- 逐文件尺寸见 `docs/asset-dimensions.csv`。
